## 1. 논문 개요

본 논문의 핵심 사항은 다음과 같다.

| 핵심 사항        | 설명                                                                                                                                 |
|--------------|------------------------------------------------------------------------------------------------------------------------------------|
| 시스템 구조 `C1`  | 4개의 에이전트를 포함한 LangGraph 파이프라인<br>- **반도체 FA (불량 분석)** 과제를 **특화된 sub-task로 분해**                                                     |
| 멀티모달 퓨전 `C2` | 다음 3가지 항목을 **LLaVA-1.6 컨텍스트** 로 통합<br>- `DINOv2` 모델의 Visual Embedding<br>- SECS/GEM 장비와의 통신을 통한 데이터<br>- Qdrant 를 통한 기존 수집된 데이터 추출 |
| 데이터셋 `C3`    | **SemiFA-930** 데이터셋<br>- 930개의 annotation 된 반도체 불량 이미지로 구성<br>- 총 class 개수는 9개                                                     |
