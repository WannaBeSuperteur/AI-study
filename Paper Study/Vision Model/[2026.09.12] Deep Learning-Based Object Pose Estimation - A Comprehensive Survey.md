## 논문 소개

* Jian Liu and Wei Sun et al., "Deep Learning-Based Object Pose Estimation: A Comprehensive Survey"
* [arXiv Link](https://arxiv.org/pdf/2405.07801)

## 1. 논문 개요

* 이 논문의 주요 내용은 다음과 같다.
  * 딥 러닝 기반 **물체의 Pose Estimation 방법** 들에 대한 **종합적 조사**
  * input data의 **주요 모달리티** (RGB, depth, RGBD 이미지), output data의 **서로 다른 자유도** 를 커버함
  * Pose Estimation의 도메인을 **instance-level, category-level, unseen object** 의 3가지로 분류

| HOPE Dataset (2022)                     | 생활용품 분야 최적화                | HOPE-Image 데이터셋은 50장면으로 구성 (각 장면은 최대 5가지의 밝기) |

| MP6D Dataset (2022)      | 금속 제품 중심               | 20,100개의 실제 이미지 (object pose label 포함) + 50,000개의 합성 이미지          |

### 3-4. 평가 메트릭

* Pose Estimation 에 사용되는 metric 들은 다음과 같다.

| 3DoF                  | 6DoF                  | 9DoF                         |
|-----------------------|-----------------------|------------------------------|
| 3개의 회전축 (x, y, z축) 기준 | 3개의 회전축 + **위치 (이동)** | 3개의 회전축 + 위치(이동) + **추가 3축** |

**1. 3DoF (3축 자유도) metric**

* 정확도 평가 기준

![image](../images/PoseEstimationSurvey_4.PNG)

[(출처)](https://ojs.aaai.org/index.php/AAAI/article/view/33123/35278) : Jian Liu and Wei Sun et al., "Deep Learning-Based Object Pose Estimation: A Comprehensive Survey"

| notation       | 설명                                                                |
|----------------|-------------------------------------------------------------------|
| $d(R_{gt}, R)$ | 비교 대상 3D 회전 $R$, $R_{gt}$ 간의 **relative deviation = angle error** |
| $tr$           | 행렬의 주대각선 성분의 합                                                    |
| $R$            | 예측된 3D 회전                                                         |
| $R_{gt}$       | ground-truth 3D 회전                                                |
| $c$            | 예측된 class                                                         |
| $c_{gt}$       | ground-truth class                                                |
| $\lambda$      | 사전 정의된 threshold                                                  |

**2. 6DoF (6축 자유도) metric**

![image](../images/PoseEstimationSurvey_5.PNG)

[(출처)](https://ojs.aaai.org/index.php/AAAI/article/view/33123/35278) : Jian Liu and Wei Sun et al., "Deep Learning-Based Object Pose Estimation: A Comprehensive Survey"

* distance map $D$ 와 픽셀 $p$ 에 대해, $D(p)$ 는 **카메라 중심과 3D point $x_p$ 사이의 거리** 를 저장한다.

| notation                       | 설명                                                                                                     |
|--------------------------------|--------------------------------------------------------------------------------------------------------|
| $\hat{P}$, $\bar{P}$           | 각각 **estimated** pose, **ground-truth** pose                                                           |
| $\hat{D}$, $\bar{D}$           | object model $M$ 에 의해 생성된 distance map (서로 다른 2개의 pose $\hat{P}$, $\bar{P}$ 기준)                        |
| $\hat{V}$, $\bar{V}$           | distance map $\hat{D}$, $\bar{D}$ 와, test image $I$ 에 대한 distance map $D_I$ 를 비교하여 생성된 Visibility Mask |
| $\tau$                         | mis-alignment tolerance                                                                                |
| $S_M$                          | object model $M$ 에 대한 global 대칭 변환                                                                     |
| $V_M$                          | object model $M$ 의 vertex                                                                              |
| $proj$                         | pixel-level 2D projection                                                                              |
| $\|\hat{D} - \bar{D}\| < \tau$ | estimated, groud-truth pose 간 **distance 의 차이가 $\tau$ 미만** 임을 의미                                       |

* **비대칭 물체/대칭 물체** 에 대한 metric으로 다음과 같은 것이 있다.

| metric                                 | 설명                                                         | 적용 대상      |
|----------------------------------------|------------------------------------------------------------|------------|
| ADD (average point distance)           | 3D model point $x \in O$ 에 대해, **평균 pairwise distance** 계산 | **비대칭** 물체 |
| ADD-S (average closest point distance) | 평균 거리를 **nearest point distance** 형태로 계산                   | **대칭** 물체  |

![image](../images/PoseEstimationSurvey_6.PNG)

[(출처)](https://ojs.aaai.org/index.php/AAAI/article/view/33123/35278) : Jian Liu and Wei Sun et al., "Deep Learning-Based Object Pose Estimation: A Comprehensive Survey"

| notation           | 설명                                                      |
|--------------------|---------------------------------------------------------|
| $R_{gt}$, $t_{gt}$ | **ground truth rotation**, ground truth **translation** |
| $R$, $t$           | **estimated** rotation, estimated translation           |

* 예측된 3D rotation, translation에 대한 **오류를 직접 정량화** 하기 위한, $n^omcm$ metric

![image](../images/PoseEstimationSurvey_7.png)

[(출처)](https://ojs.aaai.org/index.php/AAAI/article/view/33123/35278) : Jian Liu and Wei Sun et al., "Deep Learning-Based Object Pose Estimation: A Comprehensive Survey"

| notation | 설명                |
|----------|-------------------|
| $e_R$    | rotation error    |
| $e_t$    | translation error |

**3. 9DoF (9축 자유도) metric**

* 9DoF metric 으로는 $IoU_{3D}$ (IoU 컨셉) 를 사용한다.
* 즉, **ground-truth, predicted 3D bounding box 간의 IoU 값** 을 metric으로 사용한다.

$\displaystyle IoU_{3D} = \frac{P_B \cap G_B}{P_B \cup G_B}$

| notation | 설명                               |
|----------|----------------------------------|
| $G_B$    | **ground-truth** 3D bounding box |
| $P_B$    | **predicted** 3D bounding box    |

## 4. Instance-Level Pose Estimation

**Instance-Level Pose Estimation (객체 단위)** 에 사용되는 방법론은 다음과 같다.

| 방법론 분류                                                           | 방법론 설명                                                  |
|------------------------------------------------------------------|---------------------------------------------------------|
| [4-1. Correspondence (일치) 기반 방법론](#4-1-correspondence-일치-기반-방법론) | **Sparse, Dense** correspondence 방법론으로 구분               |
| [4-2. 템플릿 기반 방법론](#4-2-템플릿-기반-방법론)                               | 이미지의 **전역 정보를 이용** 함으로써, **질감이 없는 object** 를 잘 처리할 수 있음 |
| [4-3. Voting (투표) 기반 방법론](#4-3-voting-투표-기반-방법론)                 | **pixel-level 또는 point-level 의 voting** 기반 방법론          |
| [4-4. Regression (회귀) 기반 방법론](#4-4-regression-회귀-기반-방법론)         | **학습된 feature** 로부터 object pose 를 얻는 것을 목표로 함           |

### 4-1. Correspondence (일치) 기반 방법론

* Correspondence 기반 방법론은 **Sparse, Dense correspondence 로 구분** 된다.

| 구분                    | 설명                                                                                                       |
|-----------------------|----------------------------------------------------------------------------------------------------------|
| Sparse correspondence | 입력 이미지 또는 point cloud 에서 **object keypoint 를 탐지** 하여, 입력 이미지와 object model 간 **2D-3D, 3D-3D 로 일치** 하도록 함 |
| Dense correspondence  | **Sparse correspondence 기반 방법론보다 훨씬 많은 수의 correspondence** 를 이용하여, **dense 2D-3D, 3D-3D 일치** 를 생성하도록 함   |

![image](../images/PoseEstimationSurvey_8.png)

[(출처)](https://ojs.aaai.org/index.php/AAAI/article/view/33123/35278) : Jian Liu and Wei Sun et al., "Deep Learning-Based Object Pose Estimation: A Comprehensive Survey"

### 4-2. 템플릿 기반 방법론

* 템플릿 (Template) 기반 방법론은 **이미지의 전역 정보를 이용하여 질감이 없는 object를 처리(인식)** 하기 위한 것이다.
  * ground-truth object pose로 명시된 **수많은 템플릿 중 대상 물체와 가장 유사한 템플릿** 을 찾는 방법을 사용한다.

| 구분                                    | 설명                                                                                 |
|---------------------------------------|------------------------------------------------------------------------------------|
| **RGB-Based** Template Method         | 입력이 **RGB 이미지** 일 때, **pose estimation 을 이미지 추출 task 로 재구성** 하는 방법                 |
| **Point Cloud-Based** Template Method | 입력이 **point cloud** 인 경우 사용 (관측된 point cloud에 가장 가까운 **최적의 relative pose**를 찾는 방식) |

![image](../images/PoseEstimationSurvey_9.png)

[(출처)](https://ojs.aaai.org/index.php/AAAI/article/view/33123/35278) : Jian Liu and Wei Sun et al., "Deep Learning-Based Object Pose Estimation: A Comprehensive Survey"

### 4-3. Voting (투표) 기반 방법론

* Voting (투표) 기반 방법론은 **pixel-level 또는 point-level voting 을 이용하여 object pose를 탐지** 하는 것이다.
  * 방법론은 **indirect voting** 과 **direct voting** 으로 구분한다.

| 구분                  | 설명                                                                                                                                                                                              |
|---------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **indirect** voting | 다음 2가지 방법 중 하나를 사용하여, **2D-3D 또는 3D-3D keypoint correspondence** 를 이용하여 object pose 도출<br> - **pixel-level** voting 으로 **2D** keypoint 를 측정<br>- **point-level** voting 으로 **3D** keypoint 를 측정 |
| **direct** voting   | pixel-level 또는 point-level voting 으로부터 **pose, confidence를 직접 예측**<br>- indirect voting이 **keypoint 선택에 결과가 크게 좌우되는 것을 보충** 하기 위함                                                               |

![image](../images/PoseEstimationSurvey_10.png)

[(출처)](https://ojs.aaai.org/index.php/AAAI/article/view/33123/35278) : Jian Liu and Wei Sun et al., "Deep Learning-Based Object Pose Estimation: A Comprehensive Survey"

### 4-4. Regression (회귀) 기반 방법론

* Regression (회귀) 기반 방법론은 **학습된 feature로부터 object pose를 직접 얻는** 방식을 사용한다. 

| 구분                         | 설명                                                                       |
|----------------------------|--------------------------------------------------------------------------|
| Geometry-guided regression | RGBD 이미지에서의 **기하학적 정보** (3D 구조적 특징 또는 2D-3D 기하학적 특징) 를 추출하여 이용           |
| Direct regression          | 추가적인 변환 step 없이, **RGBD 이미지에서 object pose를 직접 복원**<br>- 이로 인해 **복잡도 감소** |

[(출처)](https://ojs.aaai.org/index.php/AAAI/article/view/33123/35278) : Jian Liu and Wei Sun et al., "Deep Learning-Based Object Pose Estimation: A Comprehensive Survey"

## 5. Category-Level Pose Estimation

**Category-Level Pose Estimation** 은 다음과 같은 2가지 방법론으로 구분된다.

| 방법론 분류                       | 설명                                                                                                                                                                                                                                                                                          |
|------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Shape Prior-**Based** Method | 각 class 별 object에 대한 CAD 모델을 딥러닝으로 학습시킨 후, 이 정보들을 **3D 기하학 정보** 로 사용한다.<br>- 이 3D 기하학 정보는 **해당 class의 unseen object pose estimation** 에 사용한다.<br><br>다음과 같은 2가지 방법론이 존재한다.<br>- 1. **Normalized Object** Coordinate Space (NOCS) shape alignment<br>- 2. **Direct** pose regression methods |
| Shape Prior-**Free** Method  | shape prior 를 이용하지 않는 방법으로, **일반화 성능이 비교적 높다.**<br><br>다음과 같은 3가지 방법론이 존재한다.<br>- 1. **depth**-guided **geometry**-aware<br>- 2. **RGBD**-guided **semantic and geometry** fusion<br>- 3. 그 외 방법                                                                                            |

## 6. Unseen Object Pose Estimation

**Unseen Object Pose Estimation** 은 다음과 같은 2가지 방법론으로 구분된다.

| 방법론 분류                                  | 설명                                                                                                                                                                                   |
|-----------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **CAD Model**-Based Method              | **object CAD 모델을 사전 지식** 으로 활용하여, 새로운 object에 대한 pose estimation 실시<br><br>다음과 같은 2가지 방법론이 있음<br>- 1. **Feature Matching**-Based Methods<br>- 2. **Template Matching**-Based Methods |
| **Manual Reference View**-Based Methods | unseen object에 대한 **CAD 모델을 필요로 하지 않는** 방법으로, target object에 대한 **사람이 라벨링한 reference view** 필요<br>- CAD Model-Based 와 마찬가지로, Feature/Template Matching-Based Method 로 구분             |
